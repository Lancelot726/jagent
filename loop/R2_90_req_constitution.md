# 需求宪法 · R2 修订 · jagent

> 主体见 `R1_90_req_constitution.md`（R1 定稿件，只读，不回改）。
> 本文件只登记 **R2 起生效的修订**；二者表述冲突时以本文件为准。

采用"修订页"而非整份复制，理由：宪法是项目级唯一裁定依据，
整份复制会产生两份口径，一旦只改其一即出现矛盾裁定依据。
轮次内真正需要按轮留痕的是**进度图 / 流水 / 台账 / 冻结清单**，那四个按轮新开。

## 修订 1：范围外项被本轮不动（重申）

R1 外推项**继续推迟**，本轮不取任何一项（作者 2026-09-19 明确"把你本来预设 R2 的东西推迟"）：

- 压缩摘要自引用累积修复
- 进化论基因组与变异算子
- GraalVM native 构建、native 启动/体积基准、常驻内存 RSS 基准
- 分层流程图布局、终端 raw mode 行编辑

## 修订 2：新增 R2 范围内项

| 项 | 说明 |
|---|---|
| 双档位独立厂商接入 | CHEAP / STRONG 两档各自独立的 `base_url` / `api_key` / `model` |

## 修订 3：厂商无关（新增硬性约定 #7）

**产品不得对任何具体厂商做硬编码或默认假设。** 两档的地址、密钥、模型名
**全部只能来自配置**（`work/jagent.properties` 或环境变量或命令行）。
代码、资源、文档中不得出现"DeepSeek / OpenAI / Kimi / GLM / 通义"等厂商名
作为默认值、分支条件或示例常量。

理由：本项目的主张是"方法论作用于运行时"，接入哪家模型是**部署决策**而非产品特性；
把厂商写进代码会让"两档竞价"退化为"两家特定厂商竞价"，测试价值随之丢失。

同时：作者指定的厂商身份属**部署私事**，不写入本仓库任何文件（含 `loop/`）。

## 修订 5：厂商无关须覆盖"思维链模型"（2026-09-20 G3 实跑追加）

厂商无关不能只做到"地址可配"。真实厂商中已出现**思维链（thinking）模型**：它在多轮
工具回合中要求把上一回合的 `reasoning_content` 原样回传，否则拒绝请求。
若客户端丢弃该字段，则"厂商无关"只对非思维链模型成立，实为**对模型类型的隐性硬编码**。

故约定：客户端须**捕获并回传**厂商返回的推理内容；该字段对不认识它的厂商不得发送空值。
（实现见 `OpenAiClient` / `Turn` / `Message`；断言见 `P1T`。）

## 修订 2b：范围扩至"全机制真实验证"（2026-09-19 作者追加口径）

作者追加：本轮**不止验证拍卖**，而是要"像一个能用的 agent"，把 R1 的四组机制
**在真实厂商下全部跑一遍并留下证据**。据此把修订 2 的 R2 范围内项由
"双档位接入 + 拍卖验证"扩为下表：

| 机制 | 主张 | 须留下的证据 |
|---|---|---|
| 博弈论 | 密封拍卖选档，第二价格结算 | 两档同台竞价、胜者、付款、利润、信誉漂移 |
| 经济学 | token 预算账本 + 压缩 ROI | 预算消耗曲线、压缩前后的 token 与 ROI 倍数 |
| 工程经济学 | 收益/成本对账（利润积分） | 累计利润与预算消耗同屏 |
| 控制论 | 并发闭环调参 + 熔断 | 许可上下调次数、并发峰值、熔断次数、错误率 |
| 图工程 | 执行图与计划落盘 | 节点/完成/失败计数、`work/plan.md` |

同时新增**可观测性**为本轮范围内项：以上证据须能在**一次运行结束**时一次性对账，
不得要求人工翻屏拼接。做法见 `R2_10` §8。

仍然推迟：修订 1 所列各项（含 R1 外推的 native / 进化论 / raw mode 等）**一项不动**。
