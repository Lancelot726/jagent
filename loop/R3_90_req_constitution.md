# 需求宪法 · R3 修订 · jagent

> 主体见 `R1_90_req_constitution.md`（R1 定稿件，只读，不回改）。
> 中间层见 `R2_90_req_constitution.md`（R2 修订页，只读，不回改）。
> 本文件只登记 **R3 起生效的修订**；三者冲突时以本文件为准。

采"修订页"而非整份复制（理由见 `R2_90` 开篇）：宪法是项目级唯一裁定依据，
整份复制会产生多份口径，只改其一会造成矛盾裁定依据。
按轮留痕的仍只有 **进度图 / 流水 / 台账 / 冻结清单** 四件。

## 修订 1：机制标签归入 L1（§3.5 的展开，非新增约定）

**问题**：R1 起，机制标签（竞价 / 拍卖 / 信誉 / 预算 / 利润 / 控制论 / 压缩 / 降级 / 路径互斥 / 执行图）
被放进了 `lang/*.properties`，即 **L2 层**——它们随用户语言变，中文档显示中文、英文档显示英文。

**判定**：这批标签**不是面向用户的散文，是内部协议词汇**，按硬约定 #5 本应属 L1
（内部固定英文 + 极强缩略）。放进 L2 是层次归属错误。

**修订**：这批标签固定为**英文**，取自"含义泛指的词汇"，**不带明确学科联想**。
不随 `--user-lang` 变化。面向用户的语言只作用于提示语、帮助文本、错误说明等真正的散文部分。

**幅度限定**（作者 2026-09-20 裁定）：**只改终端显示文字**。
代码类名（`Auction` / `Budget` / `Governor` 等）、lang 键名、`README.md`、`docs/` **一律不动**；
`loop/` 过程文件里的学科表述保留——那是过程记录，不是产品界面。

**替换范围**：只换最带学科色彩的六个（竞价 / 拍卖 / 信誉 / 利润 / 预算 / 控制论）。
其余（工具 / 步数 / 压缩 / 降级 / 执行图 / 轮次 / 结果）本来就中性，保持现状。

**注意**：本条改的是**呈现**，不是**机制**。博弈论/经济学/工程经济学/控制论
仍按宪法 §1 直接作用于运行时，其行为、判定逻辑与证据（`R2_50` / `R2_51`）不变。

## 修订 2：取用"终端 raw mode 行编辑"推迟项（限基础版）

R1 宪法 §5 把"终端 raw mode 行编辑"列为推迟项，R2 又整体推迟。**R3 取用**，
但作者 2026-09-20 裁定**只取基础版**：

| 项 | 本次做 | 明确不做 |
|---|---|---|
| 输入 | 提示符 + 读一行跑一行，循环到退出 | 方向键历史、行内光标编辑、Home/End、Tab 补全 |

即 R1 宪法原话里的"raw mode 行编辑"**本轮只实现其一半**（有输入循环，无 raw mode 行编辑）。
完整版（接管终端原始模式）仍属推迟项，待作者另行下令。

**理由**：先把"可以反复敲命令"这件事做出来并固定住；raw mode 要自己处理跨平台按键字节，
体量与风险都大得多，不宜与显示缺陷修复捆在同一轮。

## 修订 3：执行图不再在节点上承载长摘要

**问题**：节点摘要在两处被先后截断（`Agent.summarize` 截 60 → `GraphView.clip` 截 48），
末句必被切；即便放宽上限，把模型整段回复塞进树节点也不合图的本意。

**修订**：**树形图只画结构与状态**（节点 / 状态字形 / 耗时），不再承载模型回复的长摘要；
模型回复改为**运行结束时统一给一段总结**。

**边界**：工具节点的短结果（如 `wrote 11 bytes`）仍可保留在节点上——它们是"该节点做了什么"的
最小事实，不是长散文。判定标准是"能否一行说完"，不是固定字数。

## 修订 4：进化论项暂缓（§1 表述不动）

作者 2026-09-20：「进化论的暂时删掉」。

**修订**：进化论基因组与变异算子**从待办中移除，暂缓（无期限）**。
宪法 §1 的项目定义表述（含"进化论"字样）**维持原文不动**——作者未要求改宪法，
本条只是不再把它列为待办项。

**影响**：R1/R2 均未开工此项，故对已交付内容无影响。
