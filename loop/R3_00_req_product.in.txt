【1】执行图节点摘要显示不全
    现象：`└─ ● agent step 2  1537ms  已创建好 Markdown 文件，文件位置在：
          **`mermaid_flowchart.md…`
    原话：「这最后一句显示不全」
    裁决：「这样吧 树形图显示模式直接最后给一段总结就行了」

【2】chat 里推理与答案黏在同一行
    现象：灰色思维链结束后，答案第一个字直接接在后面
    原话：「我是。。。不应该换一行完整显示出来吗」

【3】没有可反复敲命令的输入界面
    原话：「我希望你改成模仿shell 那样可以反复敲命令回显」
    补充：「当我用--no-graph时倒是显示的挺清楚的」（--no-graph 的输出观感是好的）
    裁决：**先做基础版** —— 提示符 + 读一行跑一行，不做方向键历史与行内编辑

【4】机制标签带学科色彩
    原话：「显示的时候'竞价''工具'蓝色字体里面的中文 我希望都换成含义泛指的那种
          英文词汇不让人有明确的学科联想 还有'步数''预算''利润'」
    裁决：范围 = **只改终端显示文字**（不动代码类名 / lang 键名 / README / docs）
          幅度 = **只换最带学科色彩的少数几个**：竞价、拍卖、信誉、利润、预算、控制论

【5】进化论项
    原话：「进化论的暂时删掉」
    裁决：**暂缓**（无期限）。从待办中移除；宪法 §1 的项目定义表述不动（作者未要求改）

- 【1】【2】是**显示缺陷**：产品在真实终端里没把信息显示完整，不是设计变更。
- 【3】是**取用推迟项**：R1 宪法 §5 明确写「终端 raw mode 行编辑」推迟到 R2；
      R2 又整体推迟到 R3。R3 现在取用它，但只取基础版。
- 【4】是**口径澄清**，不是新功能：这批标签原本被放进 L2（随用户语言变），
      按硬约定 #5 本应属 L1（内部固定英文）。改的是层次归属，不是机制本身。
- 【5】是**范围收缩**：暂缓一项从未开工的推迟项，对已交付内容无影响。

四项均**不影响 R2 已冻结的机制正确性**：四组机制在真实厂商下的行为与证据不变，
改的是这些行为的**呈现方式**。
