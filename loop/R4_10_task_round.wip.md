## 5 关键决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 轮次形式 | 新开 R4，走 S0–S8 全流程 | 口径变化须退 S1 重建，不并入已冻结的 R3 |
| 作用面 | README / docs / loop **全部说明文本** | 推翻 R3_90 修订 1 的旧边界，本轮即为此而开 |
| 只读存档 | `.in.txt` 与证据件**保持原样**，另建映射表 | 「只增不改」铁律 + 证据保真 |
| §1 项目定义 | **一并改写** | 作者裁定；项目定义句本身含"方法论"与学科式列举 |
| 「成本收益」 | **禁用** | 作者明确点名 |
| 熔断的写法 | 统一作 **熔断**（不是"熔断触发"） | 与 `circuit breaker` 对齐 |
| 代码与断言 | **不动** | 本轮不触碰任何运行时行为与类名 / 键名 |
| 改法是脚本还是手改 | 机械替换用脚本（可复核条数），生硬处再手工修辞 | 替换面广、需可追溯 |
