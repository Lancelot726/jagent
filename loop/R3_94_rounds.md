## R3 · 2026-09-20 · 终端交互与显示口径

**触发**：`R3_00_req_product.in.txt`（作者在 R2 的 G3 复核现场口头下达）。

**判定**：属回溯矩阵的**混合两类**：

| 意见 | 类型 | 按矩阵应退 |
|---|---|---|
| 【1】【2】摘要显示不全 / chat 不换行 | 显示缺陷 | S5（成品不行） |
| 【3】要 REPL | **范围推进**（取用 R1 推迟项） | S1（重建口径） |
| 【4】标签中性化 | **口径变了**（层次归属错） | S1（重建口径） |
| 【5】进化论暂缓 | 范围收缩 | S1（重建口径） |

四条中三条属 S1，故**不逐条分治，整轮新开** —— 作者 2026-09-20 裁定：
四项**不并入 R2**，R2 就地按首回送审形态冻结，四项整体转 R3。

**本轮着力点**：把 R2 那台"机制都活着"的机器，变成一个**人愿意反复用**的工具 ——
能反复敲命令、输出能看全、术语不端着。

**范围**

- 内：REPL 基础版（提示符 + 读一行跑一行）；执行图改画结构与状态 + 末尾统一总结；
  `chat` 推理与答案分行；机制标签中性化（六词，只改显示层）；相应断言与回归
- 外（本轮明确不取）：
  - **完整版 raw mode 行编辑**（方向键历史 / 行内编辑 / Tab 补全）—— R1 推迟项本轮**只取一半**，见 `R3_90` 修订 2
  - 进化论基因组与变异算子 —— 作者「暂时删掉」，**暂缓无期限**
  - 代码类名 / lang 键名 / README / docs 的用词 —— 作者裁定只改终端显示文字
  - 熔断与中止策略、子 agent 工作区隔离、压缩摘要自引用、GraalVM native + RSS 基准、分层流程图布局
    —— 承接项，仍待后续轮（见文末）

**关键决策**

| 决策 | 结论 | 理由 |
|---|---|---|
| 四项怎么装轮次 | **不并入 R2，整体新开 R3** | 三条属口径变化，逐条分治会让 R2 反复重开送审 |
| 标签改哪一层 | **只改终端显示文字** | 类名/键名一改则波及全套断言，收益与风险不成比例 |
| 换词幅度 | **只换最带学科色彩的六个** | 工具/步数/压缩/降级/执行图本来就中性，无需动 |
| 标签的层次归属 | 由 L2 移入 **L1**（固定英文） | 硬约定 #5：L1 是内部词汇，L2 才是面向用户散文；当初放错了层 |
| REPL 形态 | **基础版**（提示符 + 读一行跑一行） | 先把"能反复敲"做出来并固定住；raw mode 跨平台按键风险大，不宜并轮 |
| 执行图承载 | **只画结构与状态**，回复改为末尾统一总结 | 图的本意是看结构与进度；把整段回复塞进节点，放宽上限也只是把问题推后 |
